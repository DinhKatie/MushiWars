# MushiWars
 
Mushi Wars is a work-in-progress board game made in Unity, where the goal is to protect your hero by using your squad against the other player.

A test build is available [here.](https://drive.google.com/drive/folders/1jWdnjQMCi7Nr-f8w59h3VYfLTmJ1M6Dm?usp=sharing)
The most recent version is TestBuildMushiWars2.

It is still buggy and missing features, but the general gist of the game can be seen.
